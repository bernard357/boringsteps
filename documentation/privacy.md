# Privacy Policy

The short version: there is nothing to collect, so there is nothing to disclose.
Boring steps is a static site with no accounts, no analytics, no cookies, no
trackers, and no ad networks. This page exists to make that claim checkable
rather than to ask permission for things the site does not do.

## What the site does

Boring steps is plain HTML, CSS, and a little JavaScript, served as static
files. It sets no cookies, runs no analytics, and loads no third-party scripts.
The only client-side code renders the page and the post list — none of it sends
anything anywhere.

## What the host sees

Requesting a page tells the hosting provider (GitHub Pages) what any web
request tells any server: your IP address and the page you asked for. That is
infrastructure-level logging outside this site's control — not something Boring
steps collects, stores, or uses.

## The feed

The Atom feed at `/atom.xml` is a static file. Subscribing to it in a reader is
a request between your reader and the host; the site has no feed service and
keeps no subscriber list.

## Children's privacy

The site is not directed at children and knowingly collects nothing from anyone
of any age — there is no mechanism to collect it in the first place.

## Changes

If anything about the site's data handling ever changes, this page is updated
before that change ships. There is no mailing list; check back here.
