# Options review

Three options were compared for semantic search.

- A managed vector database: strong at scale, but a new service to run and pay
  for every month.
- A local index file baked into the container image: no service, rebuilt on
  each release.
- Plain keyword search with synonyms: cheapest, weakest on paraphrase.

The team leans towards the local index file. Cost of the managed option was
estimated at 120 EUR per month for the smallest tier.
